# Market Pulse

Кабинет аналитики Uzum и Wildberries с импортом CSV и интеграцией Uzum Seller API.

Для публикации импортируйте приватный репозиторий в Vercel и задайте два секрета в настройках проекта:

- `MARKET_PULSE_PASSWORD` — случайный пароль длиной от 24 символов. Вход с именем `owner`.
- `UZUM_COOKIE_KEY` — 32 случайных байта в Base64URL. Сгенерировать значение можно командой `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"`.

Разверните проект после сохранения переменных. API-ключ Uzum со scope на чтение установите через форму «Подключить Uzum» на странице «Магазин Uzum». Подключение в другом домене нужно настроить заново.
